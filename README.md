# ⚡ NEON-OS 2099: Cybernetic Web Operating System & Interactive Creative Sandbox

A futuristic cyberpunk web operating system and interactive creative playground built with React, TypeScript, Three.js, Web Audio DSP, and Tailwind CSS.

---

## 🚀 Features & Applications

### 🎛️ 1. SynthDeck 2099 (Modular Beatmaker & Synth Studio)
- **16-step Drum Sequencer**: 808 sub-kicks, snares, open/closed hi-hats, claps, synth toms, and laser FX.
- **Polyphonic Synthesizer Lead**: Selectable oscillators (Sawtooth, Square, Sine, Triangle) with real-time Lowpass Cutoff Filter, Resonance, Delay Time, and Delay Feedback.
- **Live Cyber Keyboard**: Play melodies in real-time with mouse or keyboard keys `[A S D F G H J K]`.
- **Live Oscilloscope & FFT Spectrum Analyzer**: Real-time waveform visualizer rendered at 60 FPS.
- **Direct WAV/Audio Recording**: Record beats and export directly as audio files.
- **Genre Presets**: Synthwave Night Drive, Cyber Assault 2099, Ambient Space Colony.

### 🏎️ 2. Neon Racer 3D (High-Speed Cyber Highway Arcade)
- **3D Projection Highway Engine**: Dynamic curves, undulating hills, speed warp lines, and synthwave horizon sun.
- **Controls & Abilities**: Steer, accelerate, brake, nitro boost overdrive, and deploy EMP shockwaves (`[X]` key) to clear traffic.
- **Dynamic Pickups**: Collect green Energy Cores for score multipliers and instant nitro recharge.
- **In-Game HUD**: Real-time speedometer, distance counter, nitro gauge, and leaderboard.

### 🧪 3. Quantum Sand (Physics & Chemical Reaction Sandbox)
- **60 FPS Particle Engine**: 12+ reactive elements including Sand, Water, Fire, Gunpowder, Oil, Wood, Stone, Acid, Lava, Ice, Steam, and Laser Beam.
- **Realistic Chemical Reactions**: Fire ignites oil & gunpowder; acid dissolves barriers with vapor; lava solidifies into stone upon water contact.
- **Interactive Tools**: Brush size, Gravity Mode (Down, Up, 0-G, Invert), and pre-built scenarios (Volcano, Gunpowder Bomb, Acid Catastrophe, Multi-Fluid).

### 🧬 4. Neural Nexus (Artificial Life & Genetic Evolution Simulator)
- **Emergent Agent Simulation**: Prey and apex predator boids with genetic traits (speed, radar vision, metabolism, mutation rate).
- **Genetic Evolution & Mitosis**: Fit agents reproduce with mutations; unfit agents starve.
- **God-Mode Controls**: Spawn algae food blooms, spawn predators, trigger cosmic radiation mutation storms.
- **Live Entity Inspector**: Click any organism to inspect its real-time neural network and genome telemetry.

### 🎨 5. ChromaLab (Generative Cyber Art Studio & Fractal Zoomer)
- **Generative Flow Fields**: Dynamic Perlin curl noise particle trails with neon color palettes.
- **Mandelbrot Fractal Explorer**: Deep interactive zoom and pan with high-iteration raymarching.
- **Neon Kaleidoscope Painter**: Radial mirror symmetry brush (4X, 8X, 16X) with chromatic bloom.
- **4K Image Export**: Save and download high-resolution PNG artwork.

### 💻 6. Cyber Terminal (Hacker Console & Matrix Breach Game)
- **Interactive Shell**: 15+ commands (`help`, `hack`, `matrix`, `scan`, `crypto`, `sysinfo`, `ai <prompt>`, `cat`, `ls`, `fortune`).
- **Matrix Node Infiltration Game**: Hack security nodes under time pressure to decrypt classified files and earn credits.
- **AURA Cyber AI**: Built-in intelligent cyberpunk conversational agent.

### 🔮 7. 3D Hologram Viewer (Three.js WebGL Inspector)
- **6 Holographic 3D Artifacts**: Quantum Tesseract, Neural Core, Orbital Earth Grid, DNA Double Helix, Audio-Reactive Polyhedron, Torus Knot Matrix.
- **Audio-Reactivity**: Holograms pulsate and scale dynamically to live synthesizer frequencies.
- **Shader Styles**: Wireframe, particle point cloud, and solid holographic modes with customizable laser tints.

### 📂 8. CyberDeck Files & Text Editor
- **Virtual Filesystem**: Read classified logs, manifests, and documentation.
- **Interactive Editor**: Edit and create new documents with automatic state persistence.

### ⚙️ 9. Control Deck & Live Wallpaper Engine
- **Themes**: Cyberpunk 2077, Matrix Core, Synthwave Sunset, Tokyo Night, Arctic Cyber.
- **Live WebGL Wallpapers**: 3D Cyber Grid Horizon, Matrix Kanji Rain, Hyperspace Starfield, Fluid Flow Fields, Cyberpunk Skyline.
- **Procedural Sound FX Engine**: Procedural Web Audio clicks, sweeps, alerts, and boot chimes with master volume controls.

---

## 🛠️ Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Glassmorphic UI, Neon Scanline Shaders
- **3D & Graphics**: Three.js, Canvas 2D API, WebGL
- **Audio Synthesis**: Web Audio API DSP, MediaStream Recording
- **Icons**: Lucide React
